# 校园网自动连接助手 (CampusNet Auto-Login)

一个专为「每次开机/回宿舍都要重输校园网密码」设计的 Windows 小工具。当前版本 **v1.1.1**。
**零第三方依赖**（只用 Python 标准库），也提供打包好的 `CampusNet.exe`，不需要安装 Python。

## 安装方式

### 方式一：安装包（推荐，像正常软件一样装）

双击 **`校园网自动连接助手_v1.1.1_安装包.exe`**，标准安装向导七步：

1. **欢迎页** → 2. **使用协议**（点「我接受」）→ 3. **选择组件** → 4. **选择安装位置** → 5. 安装进度 → 6. 完成（可勾选立即打开）

- **安装位置可以自己改**：在「选择安装位置」页直接输入或点右侧按钮浏览到任意文件夹（例如 `D:\Apps\CampusNet`）。程序会先试写一次，如果该目录需要管理员权限（如 `C:\Program Files`）会当场提示你换一个，不会装到一半失败。
- 默认位置：本机已有 `D:\my own special applications` 目录时用它下面的 `CampusNet`，否则用 `%LOCALAPPDATA%\Programs\CampusNet`；都是**按用户安装、不弹 UAC**。
- 组件页可勾选：**桌面快捷方式**、**开始菜单快捷方式**、**开机自动启动**（推荐）。
- 安装完成可勾选「立即打开」，直接进入配置界面填写账号密码。

安装包带来的好处：

- **自动创建桌面图标**，以后再也不用去翻文件夹；
- **卸载正规**：`设置 - 应用 - 已安装的应用` 里能看到「校园网自动连接助手」，点卸载即可；卸载时会问**是否保留账号密码**（保留的话以后重装不用重填）；
- **升级简单**：直接运行新版本安装包覆盖安装，装回原目录，账号密码和设置自动保留；
- 安装/卸载前会自动**关掉正在运行的实例**，不会出现「文件被占用」；
- 换机器/给同学：**把这一个 exe 发过去就行**，对方双击按提示装即可。

### 方式二：免安装绿色版

不想要安装过程，就把 `CampusNet.exe` 和 `config.ini` 放在任意文件夹里直接双击运行（见下方「免安装版：快速开始」）。删除时直接删文件夹即可。

## 它能做什么

- **开机自启**：通过 Windows 计划任务安装，登录账号后自动运行（无需管理员权限）。
- **识别校内/校外**：
  - 扫描到校园网 WiFi → 自动连接，并完成门户登录；
  - 没看到校园网 → **什么都不动**，网络完全交给系统默认策略自动连接（也可选连接指定备用 WiFi）。
- **自动填账号密码登录**，支持三种认证方式：
  1. **Web 门户认证**（绝大多数校园网/宿舍网）：深澜(Srun)、锐捷 ePortal、H3C 等网页登录；
  2. **PPPoE 拨号**（宿舍宽带）：自动 `rasdial`；
  3. **仅自动连接 WiFi**：可把 WiFi 密码写进系统配置后自动连接（WPA2/WPA3/开放网络）。
- **保活**：运行期间每 30 秒检测一次，门户掉线自动重登。
- **托盘驻留**：关闭窗口不退出，自动最小化到**系统托盘**（右下角）继续运行；右键托盘图标可「打开主界面」或「退出」；内存约 10-15MB（只加载标准库，不加载图形库），且全局只允许一个后台实例。

## 免安装版：快速开始（5 步）

1. 把本文件夹解压/复制到任意位置（建议 `D:\CampusNet` 这类非系统目录）。
2. **先手动连接一次校园网 WiFi**（让系统保存该网络；如果配置里填了 WiFi 密码，本工具也能自己写入配置，可跳过手动）。
3. 双击 `CampusNet.exe` → 弹出配置界面（**无论配置是否完整，双击永远打开界面**，不会静默转后台）。
   - 主界面只需填三项：**校园网账号**、**校园网密码**、**校园网 WiFi**（点「用当前的」自动填入正在连的网络）；
   - 点「**测试登录**」看到“登录成功”即可；
   - 顶部状态行实时显示：当前网络 / 后台是否运行 / 开机自启状态。
4. 点「**开机自启**」按钮装上自启（任务计划不可用时自动改用开机启动文件夹）；想让程序**立刻**开始自动登录，点「**后台运行**」。
   以后开机、从外面回宿舍连上校园网，都会自动登录。
5. **关闭窗口 ≠ 退出**：配置完整时，关窗会询问是否「最小化到托盘」——选是则程序继续在后台跑，右下角出现图标；**右键该图标**可随时「打开主界面」或「退出」（退出即彻底结束，不占内存）。
6. 想改配置随时双击 `CampusNet.exe`；卸载自启用 `uninstall_autostart.bat`；彻底删除用「一键卸载并删除.bat」或界面上的「删除此程序」。

界面下方还有两个折叠区，功能一个都没少：
- **「更多设置(高级选项)」**：门户类型/登录页/字段名/密码编码/运营商、WiFi 加密与密码、PPPoE 拨号、校外策略、检测间隔等全部进阶设置；
- **「运行日志」**：运行详情，排查问题看这里。

> **内容太多看不到？** 展开「更多设置」后内容会超出窗口高度——窗口**右侧有滚动条，鼠标滚轮也可以直接滚动**（在日志框上滚动时滚的是日志文本）。

> **关于「测试登录」显示“已可上网，无需登录”**：这说明你当前的门户会话本来就是登录状态，工具判断无需登录是正确行为。
> 想验证自动登录流程：先在浏览器里**退出门户登录**（打开任意 http 网页点退出），再点「测试登录」，即可看到完整的探测→填密码→登录→验证过程。

## 命令行参数

| 命令 | 说明 |
|---|---|
| `CampusNet.exe`（无参数/双击） | 打开配置界面（永不静默转后台） |
| `CampusNet.exe --setup` | 打开图形化配置界面 |
| `CampusNet.exe --status` | 查看当前状态（连接/联网/门户/自启/后台实例） |
| `CampusNet.exe --run` | 前台守护运行，控制台可见日志 |
| `CampusNet.exe --daemon` | 后台静默守护运行（开机自启调用；只允许一个实例，重复启动自动退出） |
| `CampusNet.exe --once` | 立即执行一次检测+连接+登录 |
| `CampusNet.exe --install` / `--uninstall` | 安装 / 卸载开机自启 |
| `CampusNet.exe --stop-all` | 停止所有正在运行的实例（安装/卸载程序内部调用） |
| `CampusNet.exe --test-login` | 测试门户登录并打印详细信息（排障） |
| `CampusNet.exe --verbose` | 配合以上参数输出详细日志 |

界面按钮与命令行等价：**保存**=写配置、**测试登录**=--test-login、**立即执行一次**=--once、**开机自启**=--install/--uninstall 切换、**后台运行/停止后台运行**=启动/结束后台唯一实例（顺带清理旧版残留实例）、**删除此程序**=已安装时启动标准卸载程序，绿色版则卸载自启+停止后台+删除整个文件夹。

日志文件：程序目录下 `campus_net.log`。

## 三种认证模式详解

### 1. Web 门户认证（默认）

校园网最常见的形态：连上 WiFi 后随便打开一个网页会被劫持到登录页，输入账号密码上网。
程序内置 4 种门户类型（配置界面的「门户类型」）：

- **auto（自动）**：自动探测登录页，探测到 `eportal` 字样就走深澜协议，否则走通用表单。**推荐默认**。
- **srun（深澜/锐捷 ePortal）**：按深澜 ePortal 的 `?c=Portal&a=login` 协议提交，密码默认 base64 编码。
- **generic（通用表单）**：解析登录页的 `<form>`，按字段名自动识别用户名/密码输入框并提交。适合自己学校写的简单登录页。
- **custom（自定义）**：全部手动指定——登录 URL、用户名字段、密码字段、密码编码方式、额外参数。适合以上都不适用的门户。

**自定义模式怎么配**（浏览器抓包法）：
1. 连上校园网，浏览器打开登录页，按 `F12` →「网络(Network)」；
2. 输入账号密码点登录，找到那条 `login` 请求；
3. 看它的 **请求 URL** 和 **表单参数**（字段名和值）；
4. 在配置界面选 `custom`，URL 填请求地址；「用户名字段/密码字段」填对应参数名；
5. 如果密码是加密后提交的，把「密码编码」改成对应方式（base64 / 原样 / URL 编码）；
6. 需要固定参数（如运营商 `service=1`）就填进「额外参数」（`k=v,k2=v2`）。

### 2. PPPoE 拨号（宿舍宽带）

适合「宽带连接」拨号上网的宿舍：
- 模式选 `pppoe`，填连接名称（默认 `宽带连接`，可在「网络连接」里看实际名字）、宽带账号、密码；
- 程序在检测到校园网时自动拨号，成功后即可上网。

### 3. 仅连接 WiFi

- 模式选 `wifi_only`，填 SSID 和 WiFi 密码（加密方式默认 WPA2-PSK）；
- 程序会自动把该 WiFi 写入系统配置并连接，不做任何登录动作。

## 配置文件说明

程序目录下 `config.ini`（UTF-8，可用记事本编辑，建议用 `--setup` 界面改）：

```ini
[general]
mode = portal            # portal=门户登录 | pppoe=宽带拨号 | wifi_only=只连WiFi
campus_ssid =            # 校园网 WiFi 名称(SSID), 必填
poll_interval = 30       # 检测间隔(秒)
start_delay = 20         # 开机后首次检测的延迟(秒)

[wifi]
security = wpa2psk       # open | wpa2psk | wpa3psk | wpapsk
key =                    # WiFi 密码(用于自动写入配置并连接)

[portal]
type = auto              # auto | srun | generic | custom
login_url =              # 登录页地址(可自动探测)
user_field =             # 用户名字段名(留空自动识别)
pass_field =             # 密码字段名(留空自动识别)
pass_encode = base64     # raw | base64 | urlencode
isp = 校园网              # 运营商(部分门户需要)
extra_fields =           # 额外表单参数, 如 service=1,domain=school

[auth]
username =               # 校园网账号
password =               # 密码(保存时自动用 Windows DPAPI 按当前用户加密)
save_password = true

[pppoe]
enabled = false
entry = 宽带连接
username =
password =

[offcampus]
strategy = ignore        # ignore=校外不干预(推荐) | connect=连接备用WiFi
fallback_ssid =          # strategy=connect 时连接的备用 WiFi 名
```

## 工作原理

```
开机/每30秒一次:
  ├─ 扫描 WiFi + 探测互联网
  ├─ 已连接校园网?
  │    ├─ 能上网 → 什么都不做
  │    └─ 不能上网 → 探测登录门户 → 自动填账号密码登录 → 验证
  ├─ 校园网在范围内但未连接?
  │    └─ 自动连接校园网 → 登录
  └─ 没有校园网信号
       ├─ strategy=ignore → 记录一条日志, 网络交给系统(默认)
       └─ strategy=connect → 连接备用 WiFi
```

## 常见问题 (FAQ)

**Q: 测试登录失败怎么办？**
按顺序检查：
1. 账号密码是否正确（可以先在登录页手动登录验证）；
2. 「门户类型」是否选对（auto 探测失败就试 srun / generic / custom）；
3. 密码编码：深澜系一般是 `base64`，自研门户一般是 `raw`；
4. 运行 `CampusNet.exe --test-login --verbose`，把 `campus_net.log` 里“门户响应”一段发出来分析。

**Q: 我们学校是 802.1X（连接时弹窗要域账号密码），不是网页登录。**
802.1X 的用户凭据由 Windows 自己保管，第三方程序无法可靠地代填（微软未开放该接口）。
本工具仍可以帮你**自动连接这个 WiFi**（填 SSID + WiFi 密码、模式选 `wifi_only`）；
首次连接时在弹出的认证框里**勾选“记住我的凭据”**，之后 Windows 会自动完成 802.1X 认证。

**Q: 密码安全吗？**
保存在本机 `config.ini` 中，使用 **Windows DPAPI** 按当前用户加密（换 Windows 用户无法解密）。
日志绝不记录密码。如果介意，也可以在每次开机后弹出的界面里不保存密码……（当前版本保存密码才能实现全自动）。

**Q: 开机自启装在哪了？怎么彻底删除？**
开机自启有两种安装方式（安装时自动选择，日志会注明）：
- **任务计划**：任务计划程序里的 `CampusNetAutoLogin` 任务（登录时触发）；
- **开机启动文件夹**：`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\` 下的「校园网自动连接」快捷方式（在文件资源管理器地址栏输入 `shell:startup` 可直接打开查看）。

删除方式：
- **只取消开机自启，保留程序**：双击 `uninstall_autostart.bat`（或 `CampusNet.exe --uninstall`），两种方式都会被清除；
- **彻底删除整个程序**（自启 + 文件夹 + 配置 + 日志）：双击 **`一键卸载并删除.bat`**，输入 `YES` 确认即可，窗口自动关闭。

**Q: 更新了新版本怎么办？**
关掉正在运行的窗口，把新版 `CampusNet.exe` 直接覆盖旧文件即可。
开机自启指向的是程序路径，更新后依然有效，**无需重装**。

**Q: 托盘图标不见了/出现重影怎么办？**
程序异常崩溃时 Windows 偶尔会留下无效图标，把鼠标滑过托盘区域即可自动清理；仍残留可重启资源管理器或注销重登。

**Q: 会连错网吗？不会乱动我的网络吗？**
不会。只有两种动作：连配置里的校园网 SSID；或（你选了 connect 策略时）连备用 SSID。
校外时默认 `ignore`，完全不干预。

**Q: 多校园网/多个 SSID？**
当前版本支持一个校园网 SSID。多数学校教室/宿舍同一个 SSID；如果确实多个，可以复制两份程序各配一个（SSID 不同），或告诉我要支持的 SSID 列表，我可以改进。
